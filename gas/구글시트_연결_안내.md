# 구글 시트 연결 안내 (약 10분)

참가자 등록·설문·선물 지급 기록이 이 시트에 한 줄씩 실시간으로 쌓이게 하는 작업입니다.
**회사 구글 계정**으로 진행해 주세요. 마지막에 나오는 **웹 앱 URL** 하나만 전달해 주시면 앱 연결은 제가 합니다.

---

## 1. 구글 시트 만들기
1. https://sheets.new 접속 (새 시트가 열림)
2. 왼쪽 위 제목을 `에코업 도슨트 참가자` 로 바꾸기

## 2. 코드 붙여 넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** (새 탭이 열림)
2. 편집기에 있는 `function myFunction() { }` 을 **전부 지우고**
3. `ecoup-docent/gas/Code.gs` 파일 내용을 **전부 복사해 붙여 넣기**
4. 19번째 줄 `var STAFF_PIN = '0000';` 의 `0000` 을 **스태프 번호 4자리**로 바꾸기
   (안내데스크·체험 스태프만 알게. 예: `'5821'`)
5. 저장 (Ctrl+S)

## 3. 처음 한 번 실행 (시트 머리줄·스태프 번호 설정)
1. 편집기 위쪽 ▶ 실행 버튼 옆 함수 목록에서 **`setup`** 선택 → **▶ 실행**
2. "승인 필요" 창 → **권한 검토** → 회사 계정 선택
3. "Google에서 확인하지 않은 앱" 화면이 나오면 → **고급** → **(프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**
   - 직접 만든 코드라서 나오는 일반 안내입니다. 이 코드는 **이 시트 하나만** 읽고 씁니다.
4. 시트 탭으로 돌아가면 `참가자` 시트에 머리줄(티켓번호·발급시각·이름…)이 생겨 있으면 성공

## 4. 웹 앱으로 배포
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 설정
   - 설명: `도슨트 투어`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/……/exec`) 복사
5. 이 URL 을 저에게 전달해 주세요 → 앱에 연결하고 다시 배포합니다.

---

## 알아 두실 점
- **시트 공유**: 이름·휴대폰 번호가 들어가므로 공유는 **담당자만**(링크 공유 끄기). 앱은 시트를 직접 보지 않고 웹 앱을 통해서만 씁니다.
- **실시간 확인**: 응답이 들어오면 `참가자` 시트에 바로 한 줄 추가됩니다. 맨 오른쪽 숨긴 열 `기기번호`는 지우지 마세요(같은 폰 중복 발급 방지용).
- **행 직접 수정 주의**: 티켓번호·선물 지급시각 칸을 손으로 고치면 앱 화면과 달라집니다. 필요하면 스태프 화면(주소 끝 `#staff`)으로 처리해 주세요.
- **코드를 고쳐 다시 배포할 때**: 배포 → **배포 관리** → 연필(수정) → 버전 **새 버전** → 배포. (새 배포를 만들면 URL이 바뀝니다)
- **스태프 번호 바꾸기**: 19번째 줄 수정 → 저장 → `setup` 다시 실행 (기존 응답은 그대로).
- **행사 종료 후**: 개인정보 파기 — 시트 삭제(휴지통 비우기까지).
